# Sicherheit

## Unterstützte Versionen

Sicherheitsupdates gibt es jeweils nur für die letzte Minor-Version. Ältere Linien werden nicht gepflegt; bitte vor einer Meldung auf die aktuelle Version aktualisieren.

## Schwachstellen melden

- Meldung ausschließlich über GitHub: im Repository unter **Security → Report a vulnerability** (private Meldung an die Betreuer).
- Bitte **keine** öffentlichen Issues für Schwachstellen anlegen, damit Details nicht vor einem Fix öffentlich werden.
- Antwortziel: erste Rückmeldung innerhalb von 5 Werktagen.
- Es gibt keine separate E-Mail-Adresse für Sicherheitsmeldungen; der GitHub-Weg ist der einzige Kanal.
